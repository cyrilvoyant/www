Glossary: the notions of this site

Each notion used on the site is defined here, in the words of the pages that detail it.

82 notions, from persistence to the p-value. Each entry gives the definition, the unit, related notions and the page that explains it. The same glossary exists as machine-readable files.

Definitions follow the wording of the site pages. They describe a research and teaching use, not a medical recommendation.

Forecasting and evaluation

An error only makes sense against a reference: describe the signal, choose simple references, measure the gain, then add complexity only if the gain justifies it.

  • AR(2) (second-order autoregression)

    A regression on the last two known values. Raw: without removing the cycle. It measures what removing the cycle brings.

    Related:
    Deseasonalization, Extreme learning machine (ELM), Persistence
    Detailed on:
    Which forecast for which signal?
    Technical guide:
    cyrilvoyant.github.io/methods/solar-forecasting-made-simple.html
    Identifier:
    cv:ar2

  • ARTU (second-order reference)

    A second-order reference on the ratio to trend: two autocorrelations and a table give its three weights, on the last value, the value h steps earlier and the mean.

    Unit:
    dimensionless (weights)
    Related:
    CLIPER, NICE, Persistence, Ratio to trend
    Detailed on:
    NICE metrics: when RMSE hides a difference between solar forecasts
    Technical guide:
    cyrilvoyant.github.io/teaching/artu-worked-example.html
    Paper:
    doi:10.1016/j.renene.2022.04.065
    Identifier:
    cv:artu

  • BLEND (cyclostationary persistence)

    The convex combination of persistence and cyclic persistence: two positive weights adding up to 1, λ and 1 − λ, computed at each moment of the cycle.

    Unit:
    dimensionless (weights between 0 and 1)
    Special case of:
    Convex combination
    Related:
    CLIPER, Convex combination, Cyclic persistence, NICE, Persistence
    Detailed on:
    BLEND: a better persistence forecast without training a neural network
    Technical guide:
    cyrilvoyant.github.io/methods/persistence-blend.html
    Paper:
    doi:10.1016/j.apm.2026.116988
    Identifier:
    cv:blend

  • Brownian motion

    Each value is the previous one plus a random draw: memory φ = 1. Persistence wins on it.

    Related:
    Memory φ, Persistence
    Detailed on:
    Which forecast for which signal?
    Identifier:
    cv:brownian-motion

  • Clear-sky index (ratio to the clear-sky trend)

    In solar forecasting, the ratio to the clear-sky trend: irradiance divided by clear-sky irradiance.

    Unit:
    dimensionless
    Special case of:
    Ratio to trend
    Related:
    Ratio to trend, sCV, Smart persistence
    Detailed on:
    Which forecast for which signal?
    Technical guide:
    cyrilvoyant.github.io/teaching/solar-forecasting-basics.html
    Identifier:
    cv:clear-sky-index

  • CLIPER

    The convex combination of persistence and the mean. Same idea as BLEND, another partner.

    Unit:
    dimensionless (weights between 0 and 1)
    Special case of:
    Convex combination
    Related:
    ARTU, BLEND, Convex combination, Mean, Persistence
    Detailed on:
    BLEND: a better persistence forecast without training a neural network
    Technical guide:
    cyrilvoyant.github.io/methods/persistence-blend.html
    Paper:
    doi:10.1016/j.apm.2026.116988
    Identifier:
    cv:cliper

  • Convex combination (positive weights summing to 1)

    Two forecasts weighed by positive weights adding up to 1, computed on the past. Persistence and the mean: CLIPER. Persistence and cyclic persistence: BLEND.

    Includes:
    BLEND, CLIPER
    Related:
    BLEND, CLIPER, “No free lunch”
    Detailed on:
    Which forecast for which signal?
    Technical guide:
    cyrilvoyant.github.io/methods/persistence-blend.html
    Paper:

    Wikidata:
    Q2627315
    Identifier:
    cv:convex-combination

  • Cyclic persistence (cyclic persistence)

    The forecast copies the value one cycle earlier, at the same moment of the cycle.

    Related:
    BLEND, Persistence
    Detailed on:
    BLEND: a better persistence forecast without training a neural network
    Technical guide:
    cyrilvoyant.github.io/methods/persistence-blend.html
    Paper:
    doi:10.1016/j.apm.2026.116988
    Identifier:
    cv:cyclic-persistence

  • Deseasonalization (removing the cycle, seasonal adjustment)

    A known cycle is not forecast: remove it, forecast the rest, put it back.

    Related:
    AR(2), Difference to trend, Ratio to trend
    Detailed on:
    Which forecast for which signal?
    Technical guide:
    cyrilvoyant.github.io/methods/make-stationary.html
    Wikidata:
    Q622893
    Identifier:
    cv:deseasonalization

  • Difference to trend (difference to trend)

    We study y − c, the gap to the cycle c. Suited to additive noise.

    Unit:
    same as the signal
    Related:
    Deseasonalization, Ratio to trend
    Detailed on:
    Which forecast for which signal?
    Identifier:
    cv:difference-to-trend

  • Extreme learning machine (ELM) (ELM, frugal learner)

    The Extreme Learning Machine retains a random hidden layer and fits its output coefficients analytically, avoiding iterative deep-network training.

    Related:
    AR(2), MIMO (multiple-input multiple-output), Persistence
    Detailed on:

    Wikidata:
    Q21948731
    Identifier:
    cv:elm

  • Forecast evaluation (forecast verification)

    An error only makes sense against a reference: same targets, stated scope, several error norms, then a test of the difference.

    Includes:
    γ-index, MAE, NICE, nMAE, nRMSE, RMSE
    Related:
    Forecasting and evaluation, MAE, NICE, Persistence, RMSE
    Detailed on:
    How to evaluate a solar forecast against persistence

    Identifier:
    cv:forecast-evaluation

  • Forecast horizon (horizon)

    The number of steps between the last known value and the value to forecast.

    Unit:
    time steps
    Related:
    Forecastability F, NICE, Persistence
    Detailed on:
    Which forecast for which signal?
    Technical guide:
    cyrilvoyant.github.io/methods/nice-metrics.html
    Identifier:
    cv:horizon

  • Forecastability F (F indicator, forecastability)

    F = 1 + sCV × (ρmax − 1), between 1 − sCV and 1. The higher it is, the easier that horizon is to forecast.

    Unit:
    dimensionless
    Related:
    Forecast horizon, MALR (mean absolute log return), Memory φ, sCV
    Detailed on:
    sCV and F: how variable and how forecastable is solar irradiance
    Technical guide:
    cyrilvoyant.github.io/methods/solar-variability-scv.html
    Paper:
    doi:10.1016/j.renene.2025.123913
    Identifier:
    cv:forecastability-f

  • Global tilted irradiance (GTI)

    Incident solar power per unit area in the tilted plane of a photovoltaic array, measured in W/m².

    Unit:
    W/m²
    Related:
    Photovoltaic curtailment
    Detailed on:
    /tools/pv-forecasting-modes/
    Identifier:
    cv:gti

  • γ-index (gamma index)

    For each forecast pixel, the distance to the nearest observation in space, time and intensity, each divided by its tolerance. γ ≤ 1: accepted.

    Unit:
    dimensionless
    Special case of:
    Forecast evaluation
    Related:
    RMSE
    Detailed on:
    The γ-index: validating displaced solar forecasts beyond pointwise errors
    Technical guide:
    cyrilvoyant.github.io/methods/gamma-index.html
    Paper:
    doi:10.1016/j.ijforecast.2026.03.002
    Identifier:
    cv:gamma-index

  • MAE (mean absolute error)

    The mean absolute error: the average of the absolute gaps between forecast and observation.

    Unit:
    same as the signal
    Special case of:
    Forecast evaluation
    Related:
    Forecast evaluation, NICE, nMAE, RMSE
    Detailed on:
    How to evaluate a solar forecast against persistence
    Technical guide:
    cyrilvoyant.github.io/methods/nice-metrics.html
    Paper:
    doi:10.1016/j.seta.2025.104588
    Wikidata:
    Q6803609
    Identifier:
    cv:mae

  • MALR (mean absolute log return) (mean absolute log return)

    A parameter borrowed from econometrics that describes the size of relative changes. This empirical diagnostic does not replace testing the model at the intended site and horizon.

    Unit:
    dimensionless
    Related:
    Forecastability F, sCV
    Detailed on:
    Which forecast for which signal?
    Paper:
    doi:10.1016/j.energy.2015.07.089
    Identifier:
    cv:malr

  • Mean (mean of the past, climatological mean)

    The forecast is always the mean of the past.

    Related:
    CLIPER, Persistence
    Detailed on:
    Which forecast for which signal?
    Technical guide:
    cyrilvoyant.github.io/methods/persistence-blend.html
    Paper:
    doi:10.1016/j.apm.2026.116988
    Identifier:
    cv:climatological-mean

  • Memory φ (noise memory)

    The correlation between two neighbouring values of the noise. 0: none. 1: total.

    Unit:
    dimensionless (between 0 and 1)
    Related:
    Brownian motion, Forecastability F
    Detailed on:
    Which forecast for which signal?
    Identifier:
    cv:memory-phi

  • MIMO (multiple-input multiple-output) (MIMO-ELM)

    A multiple-input multiple-output architecture: one model reads the recent history of several signals and forecasts them together.

    Related:
    Extreme learning machine (ELM)
    Detailed on:
    MIMO-ELM: seven energy signals of Corsica forecast by one model
    Technical guide:
    cyrilvoyant.github.io/methods/mimo-elm-energy-mix.html
    Paper:
    doi:10.1016/j.apenergy.2026.127599
    Identifier:
    cv:mimo

  • NICE (NICEᵏ, NICEΣ, NICE index)

    The forecast error divided by that of persistence, at the same dates and horizon. 0: perfect. 1: as much error as persistence. Above 1 it is written “> 1”: worse than persistence.

    Unit:
    dimensionless
    Special case of:
    Forecast evaluation
    Related:
    ARTU, BLEND, Forecast evaluation, Forecast horizon, MAE, nRMSE, Persistence, RMSE
    Detailed on:
    NICE metrics: when RMSE hides a difference between solar forecasts
    Technical guide:
    cyrilvoyant.github.io/methods/nice-metrics.html
    Paper:
    doi:10.1016/j.seta.2025.104588
    Identifier:
    cv:nice

  • nMAE (normalized MAE)

    The mean absolute error divided by the mean of the signal.

    Unit:
    dimensionless (often in %)
    Special case of:
    Forecast evaluation
    Related:
    MAE, nRMSE
    Detailed on:
    Which forecast for which signal?
    Identifier:
    cv:nmae

  • “No free lunch” (no free lunch theorems)

    Under a uniform average over all functions of a finite problem, the average performance of the search algorithms considered coincides. This precise framework is not the distribution of real solar problems.

    Related:
    Convex combination, Persistence
    Detailed on:
    Which forecast for which signal?
    Wikidata:
    Q255847
    Identifier:
    cv:no-free-lunch

  • nRMSE (normalized RMSE)

    The RMSE divided by the mean of the signal (0 for a perfect forecast).

    Unit:
    dimensionless (often in %)
    Special case of:
    Forecast evaluation
    Related:
    NICE, nMAE, RMSE
    Detailed on:
    Which forecast for which signal?
    Identifier:
    cv:nrmse

  • P10–P90 band (P10 and P90, median and P10–P90 band)

    P10 and P90 are the 10th and 90th percentiles of the simulated results: the P10–P90 band contains the central 80 %. It describes variation between runs under the chosen parameters, not all uncertainty about a real system.

    Unit:
    same as the simulated quantity
    Related:
    Monte Carlo, Simulated data, Tunnel Load Simulator (TLS)

  • Persistence (simple persistence, naive forecast)

    The forecast copies the last known value. It is the minimal reference of any forecast.

    Related:
    AR(2), ARTU, BLEND, Brownian motion, CLIPER, Cyclic persistence, Extreme learning machine (ELM), Forecast evaluation, Forecast horizon, Mean, NICE, “No free lunch”, Smart persistence

  • Photovoltaic curtailment

    A limit on exported power below what the array could produce. The announcement may or may not be known at forecast issue time.

    Related:
    Global tilted irradiance (GTI)
    Detailed on:
    /tools/pv-forecasting-modes/
    Identifier:
    cv:pv-curtailment

  • Prediction interval coverage probability (PICP)

    Fraction of test observations that fall between the bounds of their prediction intervals.

    Related:
    Prediction interval, Split conformal prediction
    Detailed on:
    /tools/probabilistic-solar-forecasting/
    Identifier:
    cv:picp

  • Ratio to trend (ratio to trend)

    We study y / c. Suited to multiplicative noise. With c as clear sky: the clear-sky index.

    Unit:
    dimensionless
    Includes:
    Clear-sky index
    Related:
    ARTU, Clear-sky index, Deseasonalization, Difference to trend
    Detailed on:
    Which forecast for which signal?
    Identifier:
    cv:ratio-to-trend

  • RMSE (root mean squared error)

    The root mean squared error. It gives large errors more weight than the MAE.

    Unit:
    same as the signal (W/m² for irradiance)
    Special case of:
    Forecast evaluation
    Related:
    Forecast evaluation, γ-index, MAE, NICE, nRMSE
    Detailed on:
    How to evaluate a solar forecast against persistence
    Technical guide:
    cyrilvoyant.github.io/methods/nice-metrics.html

    cv:rmse

  • sCV (stochastic coefficient of variation)

    A dimensionless departure from the clear-sky curve, normalized by that curve’s scale and the chosen diffuse floor. 0: clear sky; 1: the reference case of equally likely random switching between clear sky and that floor, not an upper bound.

    Unit:
    dimensionless
    Related:

    When there are no measurements yet, no model can be trained or validated, but what is known can be simulated: a first estimate, not a measurement.

    Includes:

  • Smart persistence (clear-sky-index persistence)

    Persistence applied to the clear-sky index (SP: persistence of the clear-sky index), rather than to raw irradiance.

Radiotherapy

When the link between a radiotherapy schedule and its biological effect is known, it is computed directly with an explicit model, with no training data.

  • Biologically effective dose (BED) (BED, biological effective dose)

    Dose in grays that makes different fractionations comparable. For n fractions of dose d, the LQ model gives BED = n · d · (1 + d / (α/β)).

    Unit:
    gray (Gy)
    Related:
    Equivalent dose in 2 Gy fractions (EQD2), Fractionation, Gray (Gy), Linear-quadratic-linear model (LQL), Linear-quadratic model (LQ), LQL-Equiv, Radiotherapy, α/β ratio
    Detailed on:
    Compute, don't learn: radiobiological dose equivalence with LQL-Equiv
    Technical guide:
    cyrilvoyant.github.io/tools/lql-equiv.html
    Paper:
    doi:10.1016/j.clon.2025.103893, doi:10.1016/j.softx.2026.103085
    Identifier:
    cv:bed

  • Doubling time (Td)

    The time, in months, for the number of tumour cells to double without treatment: 9.8 months for the refractory profile, 66.6 for the responder profile in the paper.

    Unit:
    months
    Related:
    Thyroglobulin (Tg)
    Detailed on:
    Thyroid cancer and radioiodine: model first, learn only what is missing
    Technical guide:
    cyrilvoyant.github.io/methods/thyroid-radioiodine.html
    Wikidata:
    Q1424376
    Identifier:
    cv:doubling-time

  • Equivalent dose in 2 Gy fractions (EQD2) (EQD2)

    The translation of the BED into a dose given in 2 Gy fractions: EQD2 = BED / (1 + 2/(α/β)).

    Unit:
    gray (Gy)
    Related:
    Biologically effective dose (BED), Fractionation, LQL-Equiv, α/β ratio
    Detailed on:

    cv:eqd2

  • Fractionation (fractions, treatment schedule)

    For n fractions (the number of treatment sessions), each delivering a dose d in grays, physical dose is not enough to predict the biological effect, which also depends on the dose received at each fraction.

    Unit:
    n fractions of d Gy
    Related:
    Biologically effective dose (BED), Equivalent dose in 2 Gy fractions (EQD2), Gray (Gy)
    Detailed on:
    Compute, don't learn: radiobiological dose equivalence with LQL-Equiv

    Paper:
    doi:10.1016/j.clon.2025.103893
    Identifier:
    cv:fractionation

  • Gray (Gy)

    The unit of absorbed physical dose: the energy deposited per kilogram of tissue.

    Unit:
    J/kg
    Related:
    Biologically effective dose (BED), Fractionation
    Detailed on:
    Compute, don't learn: radiobiological dose equivalence with LQL-Equiv
    Identifier:
    cv:gray

  • Linear-quadratic-linear model (LQL) (LQL)

    The same curve as LQ up to the transition dose, then a straight line. Below the transition dose, the two models are identical.

    Related:
    Biologically effective dose (BED), Linear-quadratic model (LQ), LQL-Equiv, Transition dose dT
    Detailed on:
    Compute, don't learn: radiobiological dose equivalence with LQL-Equiv
    Technical guide:
    cyrilvoyant.github.io/tools/lql-equiv.html
    Paper:
    doi:10.1016/j.clon.2025.103893, doi:10.1016/j.softx.2026.103085
    Identifier:
    cv:lql-model

  • Linear-quadratic model (LQ) (LQ)

    The BED of a fraction grows along a curve with dose, at all doses: the LQ curve keeps bending upward as the dose per fraction grows.

    Related:
    Biologically effective dose (BED), Linear-quadratic-linear model (LQL), LQL-Equiv, Radiotherapy, α/β ratio
    Detailed on:

    Identifier:
    cv:lq-model

  • LQL-Equiv (BED and EQD2 calculator)

    A free, open-source (MIT) calculator of BED and EQD2 under the LQ and LQL models, in the browser. A research and teaching tool, not a medical device.

    Related:
    Biologically effective dose (BED), Equivalent dose in 2 Gy fractions (EQD2), Linear-quadratic-linear model (LQL), Linear-quadratic model (LQ)
    Detailed on:
    Compute, don't learn: radiobiological dose equivalence with LQL-Equiv

  • α/β ratio (α/β)

    A tissue-specific parameter: it describes how sensitive a tissue is to the size of each fraction. The lower it is, the more sensitive the tissue is to the dose per fraction (about 3.9 Gy for the rectum).

    Unit:
    gray (Gy)
    Related:
    Biologically effective dose (BED), Equivalent dose in 2 Gy fractions (EQD2), Linear-quadratic model (LQ), Transition dose dT

  • Thyroglobulin (Tg) (Tg)

    The blood marker followed by the radioiodine therapy model.

    Unit:
    ng/mL
    Related:

    Detailed on:

  • Transition dose dT (dT)

    The dose per fraction at which the LQL model changes from a curve to a straight line (7.8 Gy for the rectum). In the LQL-Equiv library it equals 2 α/β.

    Unit:
    gray (Gy)
    Related:
    Linear-quadratic-linear model (LQL), α/β ratio

Medical physics

How a beam of photons or neutrons crosses matter and deposits energy in it, from simple models to transport simulations.

  • Attenuation (exponential decay)

    Each thickness equal to the half-value layer halves what remains: it is an exponential decay, not a subtraction.

    Unit:
    dimensionless (transmitted fraction)
    Related:

  • BNCT (boron neutron capture therapy) (boron neutron capture therapy)

    A compound carries boron-10 to the target tissue; when this boron captures a neutron, an alpha particle and a lithium-7 nucleus deposit their energy over a few micrometres.

    Related:

  • Compton scattering (Compton effect)

    The scattering of a photon on an electron: the photon loses energy and the electron receives a kinetic energy K. The rest energy of the electron is 511 keV.

    Unit:
    keV
    Related:
    Attenuation

    Compton scattering: angle and energy sharing

  • Cross section (neutron cross section, σ(E))

    It says how readily a nucleus reacts with a neutron of energy E. It is expressed as an area, often in barns, without being the size of the nucleus or, by itself, the probability of capture.

    Unit:
    barn (area)
    Related:
    BNCT (boron neutron capture therapy), Macroscopic cross section, Mean free path, Monte Carlo

  • Half-value layer (HVL) (HVL, half-value thickness)

    The thickness of material that halves the intensity transmitted without scattering: HVL = ln 2 / μ, with μ the linear attenuation coefficient.

    Unit:
    length (cm)
    Related:
    Attenuation

    cv:half-value-layer

  • Macroscopic cross section (Σ)

    The cross section multiplied by the number of nuclei per unit volume: an inverse length. For a mixture, Σ adds these products nucleus by nucleus.

    Unit:
    inverse length (cm⁻¹)
    Related:
    Cross section, Mean free path
    Detailed on:

  • Mean free path (L = 1/Σ)

    The inverse of the macroscopic cross section, L = 1/Σ: the average distance between two collisions.

    Unit:
    length (cm)
    Related:
    Cross section, Macroscopic cross section, Monte Carlo

    Atmospheric neutrons and boron capture: how far can the idea go?

  • Monte Carlo (Monte Carlo method, Monte-Carlo)

    Simulating many times with different random draws. More histories reduce the statistical error, as 1/√N for N histories; they correct neither a wrong geometry nor wrong physical data.

    Related:

Statistics

Compare a difference with its uncertainty, measure an association or a prediction, and read a result without over-interpreting it.

  • Chi-square test (chi-squared test, χ²)

    The statistic is the sum of the contributions (O−E)²/E, with O the observed count and E the count expected under the tested hypothesis. A small p-value says the departure is hardly compatible with the hypothesis, not that it is large.

    Unit:
    dimensionless
    Related:
    p-value
    Detailed on:
    Chi-square test: observed counts, expected counts and contributions
    Wikidata:
    Q1071004
    Identifier:
    cv:chi-square-test

  • Coefficient of determination R² (R²)

    The share of variation described by the line (1 for a perfect forecast). It does not measure the importance of the association.

    Unit:
    dimensionless (between 0 and 1)
    Related:
    Influential point, p-value, Pearson correlation
    Detailed on:
    Correlation, significance and R²: distinguish the concepts
    Wikidata:
    Q192830
    Identifier:
    cv:r-squared

  • Confidence interval

    It brackets the mean of y at x₀ (95 % band, Student quantile with n − 2 degrees of freedom).

    Unit:
    same as y
    Related:
    Normal distribution, Prediction interval, Student t-test
    Detailed on:
    Regression: confidence interval and prediction interval
    Wikidata:
    Q208498
    Identifier:
    cv:confidence-interval

  • Influential point (leverage)

    A point that moves the least-squares line; leverage is its potential weight, greater the farther it lies in x.

    Related:
    Coefficient of determination R², Pearson correlation
    Detailed on:
    Regression and an influential point: move an observation

    Q16908492
    Identifier:
    cv:influential-point

  • Jarque–Bera test

    Combines skewness and excess kurtosis to assess normality. The chi-square cutoff is asymptotic.

    Related:
    Normal distribution, p-value
    Detailed on:
    /tools/jarque-bera-test/
    Identifier:
    cv:jarque-bera

  • Normal distribution (Gaussian distribution, z-score)

    The z-score is the number of standard deviations between x and the mean; Φ(z) is the probability that a standard normal variable stays below z: the area to the left of z.

    Unit:
    that of the variable; z dimensionless
    Related:
    Confidence interval, Jarque–Bera test, p-value, z test
    Detailed on:

    cv:normal-distribution

  • p-value (p value)

    The probability, if the means are equal (or ρ = 0) and the model is correct, of a result at least as extreme. It is not the probability that the hypothesis is true; it does not measure the importance of an association.

    Unit:
    dimensionless (between 0 and 1)
    Related:

    The Pearson correlation in the scatter (r) and in the population (ρ).

    Unit:

    It brackets a new observation at x₀: add 1 under the root, hence a band wider than the confidence interval.

    Sensitivity against the false-positive rate 1 − Sp as the threshold varies. The area under the curve (AUC) summarizes the test without choosing a threshold.

Thermal physics and thermodynamics

Heat exchange, engine and refrigeration cycles and Carnot limits, to size a cooling, a freezing or a heat engine.

  • Biot number (Bi)

    Internal conduction resistance compared with surface convection resistance.

  • Carnot efficiency (Carnot engine, Carnot limit)

    Efficiency η is the work W divided by the heat received Qhot; ηCarnot is its limit, reached by a reversible cycle, with no friction and no temperature gap during exchanges.

    Unit:
    dimensionless
    Related:

  • Coefficient of performance (COP) (COP)

    Heat extracted from the cold reservoir per unit of work supplied. COP > 1 is normal: it is not a percentage efficiency. Carnot limit: the maximum COP of a reversible machine between two reservoirs.

    Unit:
    dimensionless

    The energy to remove to freeze a mass of water: sensible heat (mcΔT) plus latent heat, with no temperature change in this model; average power is energy divided by duration.

Research data

The measurements, observations and simulations on which results rest: a model is only as good as its data, which must be qualified, described and licensed.

  • Accessible (A in FAIR)

    Second FAIR principle: data and metadata retrievable from their identifier through an open, standard protocol (for example HTTPS), with authentication where needed; the metadata remain accessible even when the data no longer are.

    Special case of:
    FAIR principles
    Related:
    Persistent identifier
    Detailed on:
    Are my data FAIR? A self-assessment in 20 questions
    Identifier:
    cv:accessible

  • Data license (CC BY license)

    Text that states what anyone may do with the data (copy, modify, redistribute, commercial use or not), for example CC BY (Creative Commons Attribution); without a license, nobody knows what they may do.

    Related:
    Reusable
    Detailed on:
    Models live in the data: qualify, certify, license
    Identifier:
    cv:data-license

  • Data management plan (DMP)

    Document that describes how the data of a project will be produced, described, stored and shared, often required by funders; it prepares FAIR data from the start of the project.

    Related:
    FAIR principles
    Detailed on:
    Are my data FAIR? A self-assessment in 20 questions
    Identifier:
    cv:data-management-plan

  • FAIR principles (FAIR, FAIR data)

    Four principles that make data findable, accessible, interoperable and reusable, by humans and by machines.

    Includes:
    Accessible, Findable, Interoperable, Reusable
    Related:
    Data management plan
    Detailed on:
    Are my data FAIR? A self-assessment in 20 questions
    Paper:
    doi:10.1038/sdata.2016.18
    Identifier:
    cv:fair

  • Findable (F in FAIR)

    First FAIR principle: data with a persistent identifier, described by rich metadata and listed in a catalog or repository where they can be searched.

    Special case of:
    FAIR principles
    Related:
    Metadata, Persistent identifier
    Detailed on:
    Are my data FAIR? A self-assessment in 20 questions
    Identifier:
    cv:findable

  • Interoperable (I in FAIR, interoperability)

    Third FAIR principle: data and metadata in shared formats and vocabularies (for example NetCDF-CF), readable by other software and linked to other data.

    Special case of:
    FAIR principles
    Related:
    Metadata
    Detailed on:
    Are my data FAIR? A self-assessment in 20 questions
    Identifier:
    cv:interoperable

  • Metadata (metadata record)

    Data that describe data: title, authors, period, place, variables, units, instrument, time step, processing; what one needs to know to find and reuse a dataset without opening the file.

    Related:
    Findable, Interoperable, Persistent identifier
    Detailed on:
    Models live in the data: qualify, certify, license
    Identifier:
    cv:metadata

  • Persistent identifier (PID, DOI)

    Identifier that designates an object (dataset, software, article, person) for the long term, even if its web address changes: DOI (Digital Object Identifier) for data and publications, ORCID for researchers.

    Related:
    Accessible, Findable, Metadata
    Detailed on:
    Models live in the data: qualify, certify, license
    Identifier:
    cv:persistent-identifier

  • Reusable (R in FAIR)

    Fourth FAIR principle: data that others can reuse, thanks to a clear license, a described provenance and community standards.

    Special case of:
    FAIR principles
    Related:
    Data license
