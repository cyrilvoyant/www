The thread: five steps, one way of working

Every piece of research starts with the same question: what do we already know? Depending on the answer, compute, complete a model or learn from data; then make the tool usable and demonstrate that it works. Follow the thread down: each step leads to its stories, each on its own page.

Five principles guide these steps: see the approach.

Step 1 of 5 · Is the link between causes and effects known?

Compute directly

Yes: compute it, with an explicit model.

When the link is known, compute it with an explicit model, calibrated and validated on data; learning is added only for a demonstrated benefit.

Step 2 of 5 · Is the model enough?

Hybridize

Not quite: keep it and learn only what is missing.

When the model falls short, complete it: keep the model, learn only what is missing.

Step 3 of 5 · Are the useful relations known?

Learn frugally

Not well enough: learn from data, with only the complexity that pays.

When the useful relations are not known well enough, evaluate what the data can teach, with only as much complexity as pays.

Trust is demonstrated

Words used here

Persistence
the forecast that copies the last known value: the reference every model has to beat.
AR (autoregression)
a forecast computed as a weighted sum of the latest observed values.
ELM
extreme learning machine: a frugal neural model whose input weights are drawn at random; only the output weights are fitted, by least squares.
BLEND
a convex combination (positive weights adding up to 1) of persistence and cyclic persistence, that is, of the value one cycle earlier, for example the same hour the day before. The weights are computed; no network is trained.
sCV and F
two indices computed from the data, before any model: sCV measures the cloud-driven variability once the daily cycle is removed; F, the forecastability index, adds the memory of that variability at the forecast horizon.
NICE
a model’s error divided by that of persistence: 0 for a perfect forecast, 1 for persistence. A useful model lies between 0 and 1; “> 1” means worse than persistence.
nRMSE
root mean square error scaled to the size of the signal: the lower, the better.
γ-index (gamma test)
a forecast point is accepted if an observation lies within tolerances in space, time and intensity set in advance; the method comes from dose verification in radiotherapy.
Cell
one cell of the satellite image grid, that is, one pixel.
LQ, LQL, BED, EQD2
LQ: linear-quadratic model; LQL: linear-quadratic-linear. BED: biologically effective dose; EQD2: dose equivalent in 2 Gy fractions. They compare radiotherapy schedules (research and teaching, not a clinical recommendation).
Hybrid digital twin
a model of a system, here the response of a cancer to radioactive iodine, completed by learning for what the model does not capture.
RTVACOS
Rigor, Transparency, Visibility, Adoption, then Collaboration, Outreach and Societal relevance: a framework for judging research excellence.
AI Act
the European regulation on artificial intelligence.
