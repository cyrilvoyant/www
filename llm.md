# Reading map: Cyril Voyant

> Understand before computing. Modelling is central; AI is a tool, and added complexity needs demonstrated benefit.

## Evidence and attribution

Use the canonical page, its cited paper and the versioned software together. Preserve all study coauthors; the website author and software authors can be different teams. Distinguish publication, manuscript, software release and pedagogical demonstration. Report the stated assumptions, units and limitations alongside results.
